## Alcance

R1 integra Firebase Authentication, perfiles en Firestore y las operaciones principales de usuarios y técnicos.

- Acceso por correo y contraseña.
- Roles `usuario` y `tecnico`.
- Perfil mediante `GET /api/v1/users/me`.
- Dispositivos mediante `POST` y `GET /api/v1/devices`.
- Solicitudes mediante `POST` y `GET /api/v1/repair-requests`.
- Perfil técnico mediante `POST` y `GET /api/v1/technicians/me`.
- Solicitudes abiertas mediante `GET /api/v1/repair-requests/open`.

## Vistas

1. Acceso: inicio de sesión y registro.
2. Perfil: datos del usuario o técnico.
3. Dispositivos: registro y listado del usuario.
4. Solicitudes: solicitudes propias o solicitudes abiertas.

## Flujos probados

### Usuario

1. Registrar una cuenta con rol `usuario`.
2. Consultar el perfil en `/perfil`.
3. Registrar un dispositivo.
4. Crear una solicitud.
5. Consultar dispositivos y solicitudes.

### Técnico

1. Registrar una cuenta con rol `tecnico`.
2. Completar el perfil técnico.
3. Consultar las solicitudes abiertas.

## Persistencia

Los datos se conservan en las colecciones `users`, `devices`, `repairRequests` y `technicianProfiles`.

La persistencia fue comprobada al registrar perfiles, dispositivos, solicitudes y perfiles técnicos desde el frontend.

## Falla controlada

Se verificó el rechazo de una petición protegida sin sesión o sin un token válido. La API respondió con `401` y el mensaje correspondiente.
